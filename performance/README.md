# NovaVision 代码精简与界面性能优化

本次保留原界面及全部功能入口。原发布包没有 C# 工程源码，使用有源码的 `.NET 9` 优化辅助程序集和严格限定版本的程序集补丁；Python 桥接以 `App_NovaVision/ViTooAI_Bridge` 为唯一实现，外层脚本保留命令行、模块导入和 Windows spawn 入口语义。

## 已实现

- 图片列表采用虚拟化与容器复用，分组浏览也启用虚拟化。
- 图片解码与增强在后台执行，界面仅提交最新请求。解码缓存上限 256 MiB，缓存原图尺寸；外部图像变化由文件监视器使缓存失效。
- 搜索输入防抖 150 ms，增强参数防抖 80 ms，增强算法仍执行宿主原实现。
- 标注数量按单图、标注框和集合变更增量维护，首次保留原全量统计。
- 检测任务仅在类别、任务、路径、图片集合或外部配置变化时同步数据集元数据。其他任务保留原元数据流程。
- 检测标签仅在已成功保存、文件内容与当前标注完全一致时跳过重复写入；负样本与空标签删除分别处理，保存失败不会记为成功。
- 桥接重复 DLL/PATH 初始化抽为轻量公共模块，保留训练恢复检查、稳定性补丁和 JSON 协议。

## 构建、安装与恢复

便携 Windows x64 .NET SDK 9.0.318 位于 `toolchain/dotnet`，首次下载来自微软发布元数据并验证 SHA-512。源码构建依赖 dnlib 4.5.0。这些开发工具不安装到系统，也不属于应用运行依赖。

在 PowerShell 执行：

```powershell
& .\performance\Build.ps1
& .\performance\Apply.ps1
```

`Apply.ps1` 先核对交付清单与当前应用版本；应用仍在运行时拒绝覆盖，不关闭进程。正常保存工作并关闭 NovaVision 后应用，再重新打开。也可用 `-WaitSeconds 300` 在五分钟内等待正常退出。重复安装相同版本不会再覆盖。安装备份位于 `App_NovaVision/backups/performance-20261007`。

恢复优化前的程序集及依赖清单：

```powershell
& .\performance\Restore.ps1
```

恢复前校验备份和当前版本哈希，失败不覆盖。安装或恢复中途失败会尝试还原此前状态，并保留备份。恢复仅涉及本次程序集与依赖清单；Python 桥接保留兼容精简版本，原始脚本另保存在 `backups/bridge-original`。

## 验证范围

`reports/assembly-audit.json` 核验原有方法 token、签名、非目标方法体及完整 WPF 资源，不宣称检查了所有元数据表。`PerformanceHarness.cs` 实例化真实程序集对象，并在从真实数据只读复制的 9,948 张图片隔离副本上测试保存和界面；计数基准的 10,000 个对象属于构造数据，单独标明。

回归包含受控解码取消、旧 Dispatcher 提交、解码期间 Undo/Redo、继承标注、原增强像素一致性、筛选、分组、负样本、保存失败后重试、外部类别与 YAML 配置变化。五种任务的隔离保存产物与原版本一致。7 个真实根 CLI `--help` 及入口导入测试通过；安装副本完成应用、恢复、损坏备份拒绝和中途故障恢复。

本次没有启动正式训练、改变训练配方或权重，也没有验证全部功能的完整端到端过程与用户数据上的长期稳定性。100 ms 的原生批量标注进度节流未纳入本次修改。图片文件同长度、同时间戳外部替换的立即重载竞态尚未直接实测。
